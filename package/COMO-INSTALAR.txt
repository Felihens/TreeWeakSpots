TREE WEAK SPOTS - HOW TO INSTALL / COMO INSTALAR
===============================================

Requires BepInEx for Valheim. / Precisa do BepInEx no Valheim.

MANUAL / À MÃO
1. Extract this zip.                         / Extraia este zip.
2. Open the "plugins" folder from the zip.    / Abra a pasta "plugins" do zip.
3. Copy the "TreeWeakSpots" folder into:       / Copie a pasta "TreeWeakSpots" para:
       Valheim\BepInEx\plugins\

   Result / Resultado:
       Valheim\BepInEx\plugins\TreeWeakSpots\TreeWeakSpots.dll

4. Launch the game.                           / Abra o jogo.

R2MODMAN / THUNDERSTORE MOD MANAGER
Settings > Import local mod > pick this .zip (don't extract it).
Configurações > Import local mod > escolha este .zip (sem extrair).

UPDATING / ATUALIZANDO
Delete the old TreeWeakSpots folder first. / Apague a pasta TreeWeakSpots antiga antes.

Config: press F1 in game (Configuration Manager) or edit
Valheim\BepInEx\config\felih.TreeWeakSpots.cfg. See README.md.

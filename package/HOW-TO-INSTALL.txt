TREE WEAK SPOTS - HOW TO INSTALL
===============================================

Requires BepInEx for Valheim.

MANUAL
1. Extract this zip.
2. Open the "plugins" folder from the zip.
3. Copy the "TreeWeakSpots" folder into:
       Valheim\BepInEx\plugins\

   Result:
       Valheim\BepInEx\plugins\TreeWeakSpots\TreeWeakSpots.dll

4. Launch the game.

R2MODMAN / THUNDERSTORE MOD MANAGER
Settings > Import local mod > pick this .zip (don't extract it).

UPDATING
Delete the old TreeWeakSpots folder first.

Config: press F1 in game (Configuration Manager) or edit
Valheim\BepInEx\config\felih.TreeWeakSpots.cfg. See README.md.
